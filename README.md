# TaperCheck

TaperCheck is a Louisville-first public safety reference that helps drivers learn how long temporary lane-closure merge tapers should look by posted speed.

The V1 site is a static app with no backend. It shows MUTCD-based merge taper benchmarks, a lane-line cycle measuring guide, Louisville Metro311 reporting options, and a quiet KYTC note for state-maintained routes.

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static file server.
